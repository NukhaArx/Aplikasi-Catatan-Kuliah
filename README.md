# Catatan-Kuliah
Catatan Kuliah adalah aplikasi Android berbahasa Kotlin untuk mencatat tugas dan jadwal kuliah mahasiswa. Seluruh data disimpan secara permanen di dalam perangkat menggunakan SQLite, sehingga aplikasi bisa dipakai offline dan catatan tidak hilang setelah aplikasi ditutup.

Aplikasi ini punya dua fitur utama. Daftar Tugas mencatat judul, mata kuliah, deskripsi, dan tenggat, lengkap dengan tanda selesai. Tugas yang belum selesai tampil di atas, urut dari tenggat terdekat. Jadwal Kuliah mencatat mata kuliah, hari, jam, ruangan, dan dosen, dan ditampilkan urut dari Senin sampai Sabtu. Keduanya mendukung tambah, ubah, dan hapus (CRUD) dengan validasi input, dan layar utama menampilkan ringkasan jumlah tugas yang belum selesai dan jumlah jadwal tersimpan.
